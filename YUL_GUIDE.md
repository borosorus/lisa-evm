# LISA with Forge: compile, test, and debug

Standalone `.yul` files are compiled with solc in strict assembly mode. Forge deploys the resulting creation bytecode and runs the Solidity harness.

## Compile

```bash
make build
```

This compiles [`yul/LISA.yul`](yul/LISA.yul) and writes `build/yul/LISA.bin`. The pinned compiler and EVM target are configured in `foundry.toml`; the test harness has read access to that build directory.

## Test

```bash
make test
```

`test/LISA.t.sol` deploys the generated bytecode with `create`, verifies that deployment produced runtime code, and checks that an empty program completes successfully.

Always recompile after editing LISA. The `make test`, `make trace`, and `make debug` targets do this automatically.

## Debug

```bash
make trace
make debug
```

Use `j` and `k` to step, `t` to label stack operands, and `h` for help. Follow the call into the deployed contract to inspect its opcodes. Raw bytecode deployment does not provide Yul source mappings.

Start without optimization for easier stepping, then test optimized output with:

```bash
make test YUL_FLAGS='--optimize --optimize-runs 200'
```
